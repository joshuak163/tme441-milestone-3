## Description

Milestone 3: Playing with blocks! The W robot finds and approaches a 3"x3"x3" stiff cardboard cube (under 50 grams) placed 5–50 cm away, lifts it off the ground, drives forward or backward while holding it, and flips it 90 degrees about a horizontal principal axis so a new face is on top — without damaging the block and while keeping the HuskyLens camera unobstructed.
